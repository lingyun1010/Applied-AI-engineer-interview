# Nuix interview preparation

This repository keeps the self-contained interview-preparation page for the **Nuix Principal AI Enablement Builder** role.

## Open it locally

Double-click `index.html` in Finder. It does not need a server, build step, package installation or internet connection.

From Terminal on macOS:

```sh
open index.html
```

## Update it

The complete page is in `index.html`. Keep new discussion details in the most relevant existing section, and add interview-ready English wording plus concise Chinese coaching notes where useful.

After each focused update:

```sh
git diff --check
git diff
git add index.html
git commit -m "Update Nuix interview preparation"
```

## Optional GitHub Pages publishing

This repository is already compatible with GitHub Pages because `index.html` is at the repository root. Publishing can be enabled later from the GitHub repository's **Settings → Pages** without changing the page.

Do not publish private recruiter details, contact information, confidential company information or invented claims.
