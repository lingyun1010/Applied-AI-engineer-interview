# Repository instructions

This repository contains one self-contained Nuix interview-preparation webpage.

- Preserve the current single-file, buildless structure unless the user explicitly asks to change it.
- Add new discussion details and answer examples to the most relevant existing section in `index.html`.
- Write interview answers in concise British English and use Chinese for coaching notes when helpful.
- Keep project claims truthful. Label prototypes as prototypes and do not invent metrics or production experience.
- Preserve responsive behaviour, copy buttons, navigation, accessibility and both print modes.
- Do not add external dependencies or publish the page unless the user explicitly asks.
- Make one focused, independently reviewable commit per requested update.
